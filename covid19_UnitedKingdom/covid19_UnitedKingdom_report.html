01 · Overview

Project Scope & Objectives

This project provides a comprehensive epidemiological and economic analysis of the COVID-19 pandemic in the United Kingdom, using Poland as a direct comparison country and Europe and the World as wider reference groups.

The analysis spans the full pandemic timeline — from the earliest reported cases in early 2020 through to the endemic period in 2026. It integrates health, mobility, vaccination, and economic data to build a multi-dimensional picture of how the United Kingdom navigated the pandemic compared to its Central European neighbour.

A particular focus is placed on England-level clinical detail via UKHSA data, which supplements the broader UK-level picture provided by Our World in Data.

02 · Data Sources

Five Independent Datasets

Each data source provides a distinct analytical layer — from daily case counts to quarterly macroeconomic indicators — enabling multi-dimensional coverage of the pandemic.

Source 01 · Our World in Data
COVID-19 Compact Dataset
Daily epidemiological indicators for countries and aggregate regions. Covers cases, deaths, hospitalisations, ICU occupancy, testing, vaccinations, excess mortality, reproduction rate, and stringency index. The primary backbone of the cross-country analysis.
Daily UK · Poland · Europe · World Cases & Deaths Vaccinations 2020–2026
Source 02 · Google
COVID-19 Community Mobility Reports
Daily percentage changes in mobility across six place categories — retail & recreation, grocery & pharmacy, parks, transit stations, workplaces, and residential areas — relative to a pre-pandemic baseline. Used to analyse behavioural response to lockdowns.
Daily UK · Poland Mobility 2020–2022
Source 03 · UKHSA
COVID-19 Dashboard Data
England-level clinical data from the UK Health Security Agency covering weekly deaths, daily hospital admissions, occupied beds, PCR test counts, PCR positivity, and variant composition. Used as a high-resolution national supplement for the UK analysis.
Daily & Weekly England Healthcare Variants 2020–2026
Source 04 · ONS
UK Economy Data
Office for National Statistics economic indicators for the United Kingdom: quarterly GDP, household spending and income; monthly production, CPIH inflation, house prices, and unemployment; plus Bank of England base rate events. Provides economic context for the pandemic period from 2018 onward.
Quarterly & Monthly United Kingdom GDP · Inflation Unemployment 2018–2022
Source 05 · Eurostat
Macroeconomic Quarterly Indicators
Quarterly macroeconomic indicators for European countries. Used to compare Poland with the EU average across GDP growth, employment growth, government debt, and government deficit/surplus. Complements the ONS dataset which covers the UK exclusively.
Quarterly Poland · EU-27 GDP · Employment Gov. Debt & Deficit 2018–2026
Pandemic Timeline

Key Events Covered by the Dataset

Jan 2020
First COVID-19 cases in the UK & Poland. Data collection begins.
Mar–Apr 2020
First national lockdowns. Major mobility crash. First death wave.
Dec 2020
UK vaccination rollout begins — among the fastest in Europe.
Nov 2021
Omicron variant emerges. Massive case surge, lower mortality.
2022–2023
End of mass restrictions. Transition to endemic management.
May 2026
Final data access date. Post-pandemic economic recovery analysed.

04 · Statistical Inference

Four Inferential Models

The statistical analyses move beyond description to test associations, fit regression models, and produce short-term forecasts. Non-parametric methods and HAC robust standard errors address the challenges of autocorrelated weekly time series.

01
Interactive correlation analysis · HTML
Lag Correlation Between Cases and Deaths
This visualization compares Spearman rank correlations between weekly COVID-19 cases and deaths under different lag assumptions. It is used to choose and justify the delay between reported infections and subsequent mortality.
Spearman ρ Lag selection
02
Interactive scatter plot · HTML
UK Best-Lag Cases and Deaths Scatter Plot
This scatter plot shows the relationship between lagged weekly cases and weekly deaths for the United Kingdom at the empirically selected lag. It highlights the non-linear structure of the relationship and explains why correlation and regression should not be interpreted in the same way.
Best lag Scatter plot
03
Interactive regression diagnostic · HTML
Regression R² by Cases Lag
This visualization compares regression fit across alternative lags of weekly cases. It shows that the lag used in the cases-only regression model is selected empirically rather than imposed arbitrarily.
OLS regression R² comparison
04
Interactive observed vs fitted plot · HTML
Observed vs Fitted Deaths — Lagged Cases Model
This plot compares observed weekly deaths with fitted values from the cases-only lagged regression model. It serves as a limitation check, showing that reported cases alone cannot fully reproduce the timing and magnitude of pandemic mortality waves.
Cases-only model Limitation check
05
Interactive regression diagnostic · HTML
UKHSA Hospital Admissions R² by Lag
This visualization evaluates how well lagged hospital admissions explain weekly COVID-19 deaths in England. It is used to choose the admissions lag for the hospital-burden model using UKHSA data.
Multiple OLS UKHSA data Lag choice
06
Interactive observed vs fitted plot · HTML
Observed vs Fitted Deaths — UKHSA Hospital Burden Model
This is the main hospital-burden regression visualization. It compares observed weekly COVID-19 deaths with fitted values from a model based on lagged hospital admissions, occupied beds, and PCR positivity, showing that healthcare indicators provide a stronger explanation of mortality than reported cases alone.
Hospital burden HAC robust SEs Observed vs fitted

Segmented Period Trend Prediction
This visualization presents a segmented log-linear death trend model with separate pandemic and endemic-period trends. The later-period trend is used for a cautious short-term prediction, matching the project specification while avoiding overinterpretation as a long-range forecast.

Statistical Diagnostics

Validating Methodological Choices

A dedicated diagnostics script examines whether the chosen statistical methods are appropriate for the data. Results support the use of non-parametric correlation, lagged regression, period separation, and HAC robust standard errors.

DIAG · 01
File Availability
Confirms that all processed datasets are present and readable before any analysis is run.
DIAG · 02
Missingness Analysis
Column-level and top-level missingness summaries across all datasets. Identifies variables where missing values are structural rather than errors.
DIAG · 03
Date Ranges
Verifies temporal coverage across all processed files. Flags any discrepancies between expected and actual date ranges.
DIAG · 04–06
Descriptive Statistics
Summary statistics for COVID, mobility, and UKHSA variables — by location and by period — including central tendency, spread, and skew.
DIAG · 09
Normality Tests
Formal tests for distributional normality used to justify the selection of Spearman rather than Pearson correlation for the lag analysis.
DIAG · 10
Autocorrelation
Autocorrelation diagnostics for key weekly series. Supports the use of HAC robust standard errors in all regression models.
DIAG · 11–16
Regression Diagnostics
Residual plots, R² summaries, and period-comparison statistics for all lagged and hospital-burden regression models.
DIAG · 19
Variant Dominance
Summary of variant succession in England, identifying the dates at which each variant became dominant and relinquished dominance.
05 · Preprocessing

Data Processing Pipeline

All five datasets pass through a structured preprocessing script before any analysis. The pipeline standardises formats, handles missing values, constructs derived variables, and exports daily and weekly outputs.

Common Operations Across All Sources

01
Date Standardisation
All date columns converted to datetime format. Quarter labels (e.g. 2020 Q2) converted to quarter start dates.
02
Location Filtering
Only the four selected locations are retained: United Kingdom, Poland, Europe, World (and England for UKHSA).
03
Variable Renaming & Typing
Source-specific column names standardised to project conventions. Numerical columns explicitly converted to float/int.
04
Missing Value Handling
Strategy varies by variable type: zero-fill for daily counts; forward-fill for cumulative; preserve for hospitalisation and testing gaps.
05
Derived Variables
Per-million indicators, 7-day rolling averages, mobility restriction index, and time variables (year, quarter, month, ISO week, week_start) added.
06
Pandemic Period Label
Each observation tagged as 2020–2022 (main pandemic) or 2023–2026 (endemic transition).
07
Daily & Weekly Exports
All sources produce both a daily processed file and a weekly aggregated file, enabling analysis at both resolutions.

Missing Value Strategy by Dataset

Our World in Data
Daily new cases/deaths: replaced with 0 (technical gaps in key count variables)
Cumulative cases/deaths/vaccinations: forward-filled, then initial NAs set to 0
Hospitalisation, testing, excess mortality, stringency, reproduction rate: preserved
Google Mobility
All mobility values: preserved — a missing value means unavailable data, not zero mobility (0 = at baseline)
UKHSA
All UKHSA metrics: preserved — missing means the metric was not reported, not that the true value was zero
ONS & Eurostat
Economic indicators: preserved. Invalid rows (bad dates, source notes) removed entirely during loading.
